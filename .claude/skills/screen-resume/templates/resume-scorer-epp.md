## For AI Agent Execution
### Ally Recruiting - February 2026

## EXECUTIVE SUMMARY

This document provides detailed instructions for AI agents to screen **EPP (Product Associate)** candidates using a systematic, data-driven scoring methodology. This role focuses on **eCommerce operations, product coordination, vendor management, and production workflows** — NOT traditional executive assistant work.

**CRITICAL LANGUAGE REQUIREMENT:** Conversational Mandarin (read, write, speak) is REQUIRED. Candidates without Mandarin skills should be automatically rejected with "DO NOT PROCEED" regardless of other strengths.

**CRITICAL EXPERIENCE REQUIREMENT:** At least 2 years of relevant experience in operations, product coordination, vendor management, or eCommerce support.

**CRITICAL AGE REQUIREMENT:** All candidates estimated to be >36 years old (as of 2026) must have their recommendation capped at "PROCEED WITH CAUTION" regardless of other strengths. Age must be estimated from graduation dates or stated age, and the override must be explicitly mentioned in the rationale.

## PART 1: SCORING FRAMEWORK OVERVIEW

### Six Strategic Buckets (Weighted)

| Bucket | Weight | Threshold | Purpose |
|--------|--------|-----------|---------|
| Education | 10% | None | Assess academic foundation (less critical for this role) |

| Other Factors | 5% | None | Proactivity, reliability, learning mindset |

### Final Score Calculation

```
Final Score (0-100) = [
  (Education_Equiv_0-4 × 0.10) +
  (Experience_Equiv_0-4 × 0.25) +
  (Skills_Equiv_0-4 × 0.30) +
  (Communication_Equiv_0-4 × 0.15) +
  (Context_Equiv_0-4 × 0.15) +
  (Other_Equiv_0-4 × 0.05)
] × 25
```

## PART 3: RECOMMENDATION DETERMINATION

### Step 1: Calculate Final Score

Calculate the final score (0-100) using the weighted bucket formula.

### Step 2: Determine Base Recommendation

Use the threshold assessment table (from Part 1) to determine the base recommendation based on:
1. Final Score (0-100)
2. Number of thresholds passed (0/3, 1/3, 2/3, or 3/3)

### Step 3: Apply Age Override (CRITICAL)

**Age Override Rule:**

If the candidate's estimated age > 36 years (as of 2026), apply the following override:

```
IF Estimated Age > 36:
  IF Base Recommendation is "STRONG PROCEED" OR "PROCEED" OR "PROCEED WITH QUESTIONS":
    → DOWNGRADE to "PROCEED WITH CAUTION"
    → MUST explicitly state age override in rationale

  IF Base Recommendation is "PROCEED WITH CAUTION" OR "DO NOT PROCEED":
    → KEEP original recommendation (already appropriately cautious)
    → MUST mention age factor in rationale
```

**Rationale Requirement:**

When age override applies, the "key_gaps" section MUST include:
- Estimated age calculation (show graduation year → estimated age)
- Explicit statement: "Age override applied: Estimated age [X] exceeds 36-year threshold. Recommendation capped at PROCEED WITH CAUTION."

**Example:**
```
Base Recommendation: STRONG PROCEED (Score: 92.5, 3/3 thresholds)
Estimated Age: 38 (graduated 2010 → 22 + 16 = 38)
Final Recommendation: PROCEED WITH CAUTION (Age Override Applied)
```

### Step 4: Apply Mandatory Requirement Checks

**After age override, verify mandatory requirements:**

1. **No Mandarin Skills:**
   - IF Skills raw score = 0 (no Mandarin)
   - → Final Recommendation = "DO NOT PROCEED"
   - → Rationale must state: "Candidate lacks mandatory Mandarin language requirement"

2. **Insufficient Experience (<2 years):**
   - IF Experience raw score < 2.0
   - → Final Recommendation = "DO NOT PROCEED"
   - → Rationale must state: "Candidate has less than 2 years relevant experience (minimum requirement)"

### Step 5: Finalize Recommendation

The final recommendation after all overrides and checks becomes the official recommendation in the JSON output.
